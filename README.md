# Word Miner — Jiten and Anki releases

Two separate Windows programs for mining Japanese words, sentences, screenshots and optional voice clips from games or shows.

Get the installers from [the latest release](https://github.com/RealSilversin/jiten-word-miner-releases/releases/latest):

- **JitenWordMiner-Setup-0.1.1.exe — 44.04 MB:** sends approved words to your Jiten deck; requires a Jiten API key.
- **AnkiWordMiner-Setup-0.1.1.exe — 45.32 MB:** uses local Japanese dictionaries and AnkiConnect; no Jiten account needed. Install Anki and AnkiConnect separately.

Choose either edition, or install both. They have separate shortcuts, settings and queues. Updates preserve your data and backups.

The installers are below 50 MB. Larger OCR/dictionary/optional voice components download during first-time setup. The shared `JitenWordMiner-Voice-0.1.1.zip` is downloaded automatically when voice setup is selected. After setup, Anki mining works offline with Anki running locally; download optional voice components before going offline too.

Anki supports reviewed-card replacement proposals, optional automatic approval for selected decks/templates, and reversal preserving review progress. Its optional replacement add-on is included in the program folder as `AnkiWordMiner-Replacements.ankiaddon`; install it through Anki's Add-ons dialog and restart Anki.

The miner applications are compiled. The Anki replacement add-on and some third-party runtime components include Python files. SHA256 checksums are included with each release.

This repository contains release downloads, not the main application's source. Not affiliated with jiten.moe or Anki.
