# Jiten Word Miner — releases

Downloads for Jiten Word Miner, a Windows program that reads the Japanese on your
screen (a game, a show) and adds the words you don't know yet to your Jiten deck,
with the sentence, a screenshot and, if you like, the spoken line.

Get the latest **JitenWordMiner-Setup-*.exe** from
[Releases](https://github.com/RealSilversin/jiten-word-miner-releases/releases).
The `-Voice-*.zip` beside it is fetched by the program itself when you turn on
voice clips; you don't need to download it.

This repository holds only the released files. Not affiliated with jiten.moe.
